# Accessibility

ReorderWitness is a **command-line program**, not a graphical application or hosted website. Its interface uses plain text (without color-dependent status indicators), and confirmed differences are also saved in text and structured JSON files.

No formal accessibility audit or assistive-technology compatibility certification has been performed. Terminal behavior may vary by operating system and shell.

If an error message, CLI workflow, example, or documentation page is hard to use with a keyboard, screen reader, or other assistive technology, please [open an issue](https://github.com/alkinbg/ReorderWitness/issues/new/choose). Include the affected command or document, your environment, the barrier, and an expected improvement. Do not include sensitive data.
