# Code of Conduct

ReorderWitness welcomes constructive collaboration from people with different backgrounds and levels of experience.

## Expectations

Be respectful and specific when discussing code or ideas. Assume good faith, welcome questions, and give actionable technical feedback. Disagreement is normal; personal attacks are not.

Harassment, discriminatory or threatening language, insults aimed at individuals, doxxing, and publishing another person's private information are not acceptable. These expectations apply to repository issues, pull requests, code review, and other project-related discussions.

## Reporting concerns

For project conduct concerns, contact the maintainer privately at the email address publicly listed on [the maintainer's GitHub profile](https://github.com/alkinbg) (currently `alkinbg@gmail.com`). Include relevant links and context, but avoid forwarding sensitive personal information unnecessarily.

GitHub's own reporting mechanisms are also available for abuse on the platform. For security vulnerabilities, use the separate [private security reporting process](SECURITY.md).

## Moderation

The maintainer may edit or remove inappropriate comments, close discussions, reject contributions, or restrict participation when needed. Reports will be considered in context and handled as discreetly as practical. No fixed response-time guarantee is offered.

This code of conduct is intentionally short and project-specific; it does not represent a formal enforcement service.
